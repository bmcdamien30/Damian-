# GarnettWork

Marketing website for GarnettWork — a strategic consulting brand. Static site, no build step required.

## Structure

```
index.html        Page markup
css/style.css      Styles (dark/gold luxury theme, animations, responsive)
js/main.js         Interactions (nav, scroll reveal, counters, form)
assets/images/     Logo and image assets
```

## Run locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000

## Deploy

This is a static site — it can be deployed as-is to GitHub Pages, Netlify, Vercel, or any static host.
